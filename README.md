# HJB Matching

Code for reproducing figures from the HJB matching paper.

## Requirements

- **Fig 2 & Fig 4**: JAX, Haiku (`dm-haiku`), Optax
- **Fig 3**: PyTorch, torchvision

## Code

| Script | Description |
|--------|-------------|
| `codes/code_fig2_4gaussian.py` | Fig 2 — 4-Gaussian target |
| `codes/code_fig2_swissroll.py` | Fig 2 — Swiss roll target |
| `codes/code_fig2_two_moon.py` | Fig 2 — Two moons target |
| `codes/code_fig3_image.py` | Fig 3 — MNIST image generation |
| `codes/code_fig4_lensing.py` | Fig 4 — Gravitational lensing |
